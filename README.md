# UNICEF Activity Heatmap

Interactive mapping and data collection platform for UNICEF-supported humanitarian activities in Kharkiv Oblast, Ukraine.

The project consists of:

- Interactive activity heatmap and analytics dashboard
- Data collection form
- Humanitarian activity filtering and visualization
- Geographic hierarchy (district → community → settlement)
- Support for distributions, mobile medical teams, emergency response, cash assistance, repairs, trainings and other activities

## Features

- Interactive map based on Leaflet
- Heatmap visualization
- Marker clustering
- Dynamic filtering
- Multilingual interface (UA / EN)
- UNICEF activity reporting
- Mobile-friendly responsive design
- OpenStreetMap and Carto Voyager support
- Screenshot export
- Historical activity analysis
